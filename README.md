# Flutter Lab Sheet 4

Flutter Navigation and Multi-Screen Applications — 25 programs.

## Run on Chrome

```bash
cd ~/Desktop
git clone https://github.com/NetraChauhan/flutter_lab_sheet_4.git
cd flutter_lab_sheet_4
flutter pub get
```

Run any question separately:

```bash
flutter run -d chrome -t lib/program_01.dart
```

Press `q` to stop, then change the program number for the next question, up to `program_25.dart`.
